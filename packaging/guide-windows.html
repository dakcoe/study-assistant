Study AI 시작하기

처음 한 번만 하면 됩니다.

1. 설치

  1. 압축을 풀어 나온 StudyAI 폴더를 원하는 곳에 둡니다.
  2. 폴더 안의 StudyAI.exe 가 실행 파일입니다. 폴더째 두어야 돌아갑니다.

2. 처음 열기

StudyAI.exe 를 두 번 누르면 파란 경고창이 뜹니다. 정상입니다.

  1. 창에서 추가 정보 를 누릅니다. 작게 적혀 있습니다.
  2. 아래에 나타나는 실행 을 누릅니다.

개발자 등록을 하지 않은 프로그램이라 나오는 경고입니다. 다음부터는 그냥 열립니다.

3. 열쇠 넣기

AI를 쓰려면 무료 열쇠(API 키)가 하나 필요합니다. 카드 등록은 없습니다.

  1. console.groq.com/keys 에 구글 계정으로 로그인합니다.
  2. 오른쪽 위 + Create API Key → 이름은 아무거나 → Submit
  3. 만들어진 키를 복사합니다. 창을 닫으면 다시 볼 수 없습니다.
  4. Study AI의 ⚙ 를 누르고 Ctrl+V 로 붙여넣은 뒤 확인.

4. 받아 적기

  1. 소리 입력에서 무엇을 들을지 고릅니다 — 마이크, 또는 시스템 전체 소리(유튜브·줌 등).
  2. 마이크 버튼을 누르면 시작합니다. 처음에는 권한을 물어보니 허용해 주세요.
  3. 말이 끊길 때마다 왼쪽에 글이, 오른쪽에 번역이 쌓입니다.
  4. Save note 로 저장합니다. 누르지 않아도 자동으로 보관됩니다.

소리가 안 잡히면 Windows 설정 → 시스템 → 소리 에서 기본 출력 장치를 확인하세요.

더 자세한 설명은 앱 안의 ? 버튼에 있습니다.
문제가 생기면 여기에 남겨주세요.
