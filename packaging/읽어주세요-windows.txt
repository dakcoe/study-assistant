Study AI (Windows) — 설치 안내


1. 압축을 풀고 폴더째 옮기세요

   StudyAI 폴더 안의 StudyAI.exe 가 실행 파일입니다.
   폴더 안 파일들이 함께 있어야 하므로 exe만 따로 꺼내지 마세요.

   바로가기를 만들려면 StudyAI.exe 우클릭 > 바로 가기 만들기.


2. 처음 실행할 때

   "Windows의 PC 보호" 라는 파란 창이 뜹니다.
   [추가 정보] 를 누르고 [실행] 을 누르세요. 처음 한 번만 하면 됩니다.

   개발자 인증서로 서명하지 않은 프로그램이라 나오는 경고입니다.


3. API 키 넣기 (무료, 10초)

   1) https://console.groq.com/keys  접속해서 로그인
   2) 오른쪽 위 [+ Create API Key] 누르기
   3) 이름은 아무거나, 만료(Expiration)는 그대로 두고 [Submit]
   4) 만들어진 키를 복사
   5) 앱의 톱니 버튼 > API 키 칸에 붙여넣고 [확인]

   카드 등록이 필요 없고, 한도를 넘어도 요금이 청구되지 않습니다.


4. 소리 받아 적기

   마이크        — 목록에서 마이크를 고르면 됩니다.
   시스템 소리   — "시스템 전체 소리" 를 고르면 스피커로 나가는 소리를 받아
                  적습니다. 유튜브, 줌, 강의 영상 모두 잡힙니다.

   ※ 맥판에 있는 "앱별 소리" 는 Windows에서 지원하지 않습니다.
     시스템 전체 소리로 대신하세요.

   소리가 안 잡히면 Windows 설정 > 시스템 > 소리 에서 기본 출력 장치가
   실제로 소리 나는 장치인지 확인하세요.


5. 설정 저장 위치

   %APPDATA%\StudyAI\

   받아 적은 내용은 그 안 notes\autosave 에 자동 저장되고 30일 뒤 지워집니다.


자세한 설명은 앱 안의 ? 버튼(도움말)에 있습니다.
