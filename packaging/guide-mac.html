Study AI 시작하기

처음 한 번만 하면 됩니다.

1. 설치

  1. 왼쪽의 Study AI 아이콘을 오른쪽 Applications 폴더로 끌어다 놓습니다.

2. 처음 열기

응용 프로그램에서 Study AI를 두 번 누르면 열 수 없다는 경고가 뜹니다. 정상입니다. 한 번만 허용해 주면 됩니다.

  1. 경고창을 닫습니다.
  2. 시스템 설정 → 개인정보 보호 및 보안 으로 갑니다.
  3. 화면을 맨 아래까지 내립니다. "Study AI이(가) 차단되었습니다"라는 문구가 보입니다.
  4. 옆의 그대로 열기 를 누릅니다.

개발자 등록(연 $99)을 하지 않은 앱이라 나오는 경고입니다. 다음부터는 그냥 열립니다.

3. 열쇠 넣기

AI를 쓰려면 무료 열쇠(API 키)가 하나 필요합니다. 카드 등록은 없습니다.

  1. console.groq.com/keys 에 구글 계정으로 로그인합니다.
  2. 오른쪽 위 + Create API Key → 이름은 아무거나 → Submit
  3. 만들어진 키를 복사합니다. 창을 닫으면 다시 볼 수 없습니다.
  4. Study AI의 ⚙ 를 누르고 붙여넣은 뒤 확인.

4. 받아 적기

  1. 소리 입력에서 무엇을 들을지 고릅니다 — 마이크, 또는 유튜브·줌 같은 컴퓨터 소리.
  2. 마이크 버튼을 누르면 시작합니다. 처음에는 권한을 물어보니 허용해 주세요.
  3. 말이 끊길 때마다 왼쪽에 글이, 오른쪽에 번역이 쌓입니다.
  4. Save note 로 저장합니다. 누르지 않아도 자동으로 보관됩니다.

컴퓨터 소리를 고르면 "화면 기록" 권한을 물어봅니다. 화면은 찍지 않고 소리만 가져옵니다.

더 자세한 설명은 앱 안의 ? 버튼에 있습니다.
문제가 생기면 여기에 남겨주세요.
