# Study AI

강의를 **받아 적고**, **번역하고**, 모르는 걸 **AI에게 물어보는** 앱입니다.
마이크 소리는 물론 유튜브·줌처럼 컴퓨터에서 나는 소리도 텍스트로 기록합니다.

무료입니다. 카드 등록도 필요 없습니다.

## 받기

**[⬇ 다운로드](https://github.com/dakcoe/study-assistant/releases/latest)**

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| 맥 (2020년 이후 · M1~M4) | `StudyAI-macOS-AppleSilicon.dmg` |
| 맥 (2020년 이전 · 인텔) | `StudyAI-macOS-Intel.dmg` |
| 윈도우 | `StudyAI-Windows-x64.zip` |
| 윈도우 (ARM 노트북) | `StudyAI-Windows-arm64.zip` |

맥 사양은 왼쪽 위 사과 → **이 Mac에 관하여**에서 확인합니다. `Apple M…`이라고 쓰여 있으면 Apple Silicon입니다.

## 설치

**맥** — dmg를 열고 앱을 `Applications` 폴더로 끌어다 놓습니다. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면, 터미널에 아래 한 줄을 붙여 넣고 엔터를 누르면 그 뒤로는 그냥 열립니다.

```
xattr -cr "/Applications/Study AI.app"
```

**윈도우** — 압축을 풀고 폴더째 원하는 곳에 둡니다. `StudyAI.exe`가 실행 파일입니다. 처음 열 때 파란 경고창이 뜨면 **추가 정보 → 실행**을 누릅니다.

두 경고 모두 개발자 인증서로 서명하지 않은 프로그램이라 나오는 것입니다.

## API 키 넣기 (10초)

앱이 AI에게 물어보려면 열쇠 하나가 필요합니다. 무료입니다.

1. [console.groq.com/keys](https://console.groq.com/keys) 접속해서 로그인
2. 오른쪽 위 **+ Create API Key**
3. 이름은 아무거나, 만료는 그대로 두고 **Submit**
4. 만들어진 키를 복사
5. 앱의 **⚙** 버튼 → API 키 칸에 붙여넣고 확인

## 쓰는 법

앱을 켜면 받아적기 창이 뜹니다.

1. **소리 입력**에서 무엇을 받아 적을지 고릅니다 — 마이크 / 특정 앱 소리 / 시스템 전체 소리
2. 마이크 버튼을 눌러 시작합니다
3. 말이 끝나고 잠시 조용해지면 그 구간이 왼쪽에 글로 나타나고, 오른쪽에 번역이 붙습니다
4. **Save note**로 저장합니다

받아 적은 내용은 저장을 누르지 않아도 자동으로 보관되고, 30일 뒤 지워집니다.

아래 **채팅 보이기**를 누르면 AI에게 질문하는 창이 열립니다. 어디서든 글을 복사하면 그 내용이 채팅창에 들어옵니다.

더 자세한 설명은 앱 안의 **?** 버튼에 있습니다.

## 알아둘 것

- 받아 적은 음성과 질문은 [Groq](https://groq.com) 서버로 전송됩니다. 기밀 회의나 개인정보에는 쓰지 않는 편이 안전합니다. Groq은 약관에서 입력을 모델 학습에 쓰지 않고 요청 데이터를 기본적으로 저장하지 않는다고 밝히고 있습니다.
- 인터넷이 필요합니다.
- 맥은 macOS 13 이상, 윈도우는 10 이상입니다.
- 맥에서 앱 소리를 받아 적으려면 "화면 기록" 권한을 허용해야 합니다. 이름과 달리 화면은 찍지 않고 소리만 가져옵니다.
